# Personal Web Portfolio & Digital Resume

A fully responsive, modern web portfolio built from scratch to showcase my engineering background, technical stack, and software development projects.

## Features

- **Responsive Design:** Fluid layouts optimized for seamless viewing across desktops, tablets, and mobile devices using CSS Flexbox and Grid.
- **Interactive Project Showcase:** A curated gallery highlighting my work in Flutter, Python, C#, and SQL.
- **Dynamic Elements:** Vanilla JavaScript implementation for smooth scroll behaviors, interactive UI components, and contact form handling.
- **Performance Optimized:** Clean semantic HTML structures and minified asset considerations for fast page loading speeds.

## Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Modern CSS3 (Custom properties/variables, Flexbox, Grid, Media queries)
- **Interactivity:** Vanilla JavaScript (ES6+ DOM manipulation)
